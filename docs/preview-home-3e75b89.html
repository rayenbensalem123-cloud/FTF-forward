What changed

  • The header is now the model's: a full-bleed red bar, edge to edge. The earlier attempt was an inset rounded bar, which read as a button -- that is what felt old. Breaking out to the screen edges is what makes it read as a header. The crest sits on a white disc so it keeps its own contrast against the red.
  • The pill row is new and it does something. Seniors / U-20 / U-17 switch the age category, and the player lists on the screen follow it -- players carry a category field, so the filter is real rather than decorative.
  • The hero is now a photo card. The next match sits on assets/home-bg.jpg with a dark gradient so the type reads, and carries one full-width call to action. The old gradient card had a countdown and three competing buttons; the photo is what makes it read as a broadcast card rather than a panel.
  • Section titles are white, see-all links and tile icons are red. Red #E30613 is the federation's own colour, promoted from a status colour to the thing that says "this is tappable". Gold stays where contrast actually needs it.
  • Colours are untouched. Navy page, gold accent, red for danger -- every value above is transcribed from theme.ts, nothing invented.
