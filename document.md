# Document

## Objectif

Décrivez ce qu’Open Design doit générer, modifier ou décider à partir de ce document.

## Comment utiliser ce document

- Utilisez n’importe quel format Markdown : titres, tableaux, checklists, liens, citations, blocs de code et images.
- L’agent Open Design peut lire, modifier et utiliser ce fichier comme contexte de projet.
- Collez des images ou glissez des fichiers image dans l’éditeur ; les images importées sont insérées à l’emplacement du curseur.

## Guide de scénario

Pour les prototypes, décrivez l’objectif produit, les utilisateurs cibles, les flux, écrans, modules, états d’interaction, breakpoints responsive et tokens de design comme couleur, typo, espacement, rayon et motion.

## Étape suivante

Relisez et modifiez ce document, puis demandez à Open Design de générer, réviser ou travailler à partir de lui.
